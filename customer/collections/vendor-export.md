# Vendor export

Preview and download files sent to (or archived from) the collections vendor.

## When to use it

Use **Vendor Export** in the Collections module when you need to review the outbound placement, payment, or closed-case file before or after download.

## Preview an export file

1. Open **Collections** → **Vendor Export** (wording may vary slightly by build).
2. Locate the archived export run you need.
3. Choose **View** to open the in-app preview.
4. Review the tabs for **placements**, **payments**, and **closed** cases (as present for that file).
5. Download the displayed file from the preview when you need a local copy.

Cash / remittance decreases that already appear as payments are not duplicated as vendor ADJUSTMENT rows in the export.
