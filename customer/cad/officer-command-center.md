# Officer Command Center

The header **PATROL** button opens the Officer Command Center. This release shows it to Thin Line full support only. Agency officers do not see it.

Starting a stop creates a CAD call. The start actions stay off unless that person can self-dispatch or has full CAD modify. The API applies the same rule.

A supervisor with the patrol supervisor claim, and full support, can open **Patrol Stops** and review stops, including overdue ones. Shift location is on the officer’s profile.
