# Warrant Map

Align court-owned and law-enforcement warrant records when ownership or linkage needs to be corrected.

## Open Warrant Map

1. Open **Warrants** → **Warrant Map**.
2. Search for candidate pairs using the filters on the screen.
3. Open a pair to compare court and LE sides before acting.

## Common actions

| Action | Use when |
|--------|----------|
| **Link** | Records should stay related without changing ownership |
| **Adopt** | Court should take ownership of an existing LE warrant (no new court warrant) |
| **Transfer** | Ownership should move between court and LE per agency process |
| **Bulk transfer** | Multiple eligible pairs need the same ownership change |
| **Print PDF** | You need a paper comparison / audit of the mapped pair |

Exact eligibility depends on warrant status, agency settings, and your claims. If an action is disabled or returns unauthorized, stop and escalate — do not create a second warrant to work around ownership.

**Warrant numbers must be unique across agencies.** Transfer and map actions that would create a duplicate warrant number are blocked with a clear error — resolve the collision (or choose a different number) before retrying.
