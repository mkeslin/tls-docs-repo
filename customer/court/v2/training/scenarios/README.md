# Scenarios

1. **When to use** it
2. **Who** takes part
3. **At the counter** with the tablet
4. **On paper**
5. **Online** through the violator portal
6. **Judge** review
7. **After approval**
8. **Can't or blocked**

## Rules that apply to every scenario

- A case can have only one open request at a time. A second request can start after the judge decides the first, or after it's revoked or cancelled.
- Submitting a request doesn't change the case. The judge's ruling does.
- On paper, the clerk checks the signed form and keeps it in the physical packet.
