# Child Safety Seat and Seat Belt Fines

Comptroller form **40-138**. Half of the base fines collected on child safety seat and child seat belt cases is due to the state.

## What the report includes

- Transportation Code **545.412** (child safety seat) and **545.413(b)** (child seat belt).
- Only the base fine that was collected. The local child-safety fund fee is not included.
- Adult seat belt, Transportation Code 545.413(a), is not included.
- A year with nothing collected remits nothing.

## Fiscal year

The year is the court agency's fiscal year. Set **Fiscal Year Start Month** on Agency settings → General. October is the default. The report you can create is the fiscal year that has already ended.

## Create and post

1. Open **Import/Export** → **Seat Belt Fine Report**.
2. Create the report for the fiscal year ending date shown.
3. Review the collected total and the amount due to the state (half of the collected base fines).
4. Open the **Form 40-138** tab to print the comptroller form.
5. Post the report when the remittance is ready. Posting adds the city's net entry to the **GL Export Queue**.
6. Void reverses that entry in ThinLine. A file the city has already imported is reversed in the city ledger.

A posted report is complete on Court Violations → **Reporting Status** and appears on the dashboard as **Child Safety Seat and Seat Belt Fines**.
