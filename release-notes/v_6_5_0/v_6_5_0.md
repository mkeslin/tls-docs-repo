# Version 6.5.0

Welcome to the 6.5.0 release of Thin Line RMS/CAD. This line builds on 6.4.11 with major CAD improvements, criminal trespass workflow, and patrol/officer command center foundations.

## CAD — dispatch and call handling

- Redesigned dispatch board and call sheet surfaces (cards, units, activity log, notes)
- **Call templates** with quick actions; default **traffic stop** and **on view** templates; option to show templates on self-dispatch
- **Scheduled calls** and improved split/add-call flows
- **Follow-up calls** from closed calls (parent/child linkage and UI cues)
- **Caller identity** on the call sheet; caller person types aligned with incident person types
- **Call disposition** validation and clearer disposed-call presentation
- **Call phone number** on the sheet, person card, and call sheet search (including city)
- **Dispatcher checkup** timers with pause/resume, history, and unit checkup events
- **Unit notes**, unit status messages, and clearer unit/board layout
- **CAD notification sounds** and per-user audio preferences (CAD-focused)
- **Keyboard navigation** where configured for your agency
- **Read-only dispatcher** experience and session hardening where required
- **Mobile-friendly** call sheet improvements
- **AVL** on CAD: tracking toggle, map integration, and agency access rules
- Clearer handling when another user changes the same call (fewer silent overwrites)
- Improved call sheet search highlighting, dialog UX, and reporting

## Criminal trespass

- End-to-end workflow and details UI (including **narrative** tab)
- Stronger validation; nullable subject where appropriate; required officer rules
- **Record group** integration; attachments; header and reporting/PDF improvements
- Search and master records integration updates
- **Patrol trespass notice** flow (editor, PDF preview) tied to the criminal trespass record

## Patrol / Officer Command Center *(agency rollout — navigation may be hidden)*

- Officer dashboard: **traffic stops**, citation tray, outcomes, **citation notes**, PDF preview
- **Shift location** control; **patrol from this stop**; tray sync and closed-call views
- **Live CAD integration**: call updates for active units, quick actions, use cases from live calls
- **Map panel**: live GPS, follow mode, extents, add call, unit/call routing, dark-mode map styling
- **Suspicious activity** and **lost & found** use cases
- **Recent artifacts** and **session history**
- **Patrol notification sounds**
- **Mobile citation sync** improvements for iOS

## Admin / navigation

- **Fire incidents, equipment, fleet**, and standalone **trespass** admin entries remain hidden until product-ready
- **Patrol Command Center** navbar button hidden until product-ready
- **AVL tracking** behind an agency/feature toggle; geolocation permission UI only when tracking is enabled

## General Changes

- Dialog and layout consistency improvements across CAD and patrol flows
- Made other small improvements and fixes
