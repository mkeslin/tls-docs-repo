# Version 6.6.0

Welcome to the 6.6.0 release of Thin Line RMS/CAD. This line follows 6.5.3.

## Court

- **File Complaint** fills the appearance date from the offense date and the court's appearance-day setting. When the court counts business days, those are weekdays. Holidays are not skipped. A case that starts from a citation still uses the citation's appearance date.
- On an offense card that offers shortcuts, **Search** and the shortcut menu are one button.
- **Summons for Defendant** prints the defendant, address, appearance, court hours, court address, offense, and the person who swore to the complaint, when the case has them. The signature block is the court's seal and the judge's name. The officer's return is left blank for the officer who serves it.
- Court Violation Search, the work queues, the accounting batch searches, OmniBase submissions, jail custody details, the visitor log, and the mobile citation list scroll inside the page again.

## Citations

Three charges are available so a compliance dismissal can name the exact offense:

- Operate a vessel with an expired certificate of number (Parks and Wildlife Code 31.021)
- Fail to possess a commercial learner permit and driver license (Transportation Code 522.011(a)(2)(A)). The holder can bring both to court.
- Commercial learner permit holder not accompanied by a qualified commercial driver license holder (Transportation Code 522.011(a)(2)(B))

The older combined commercial learner permit operation violation is no longer offered on new citations. A citation that already uses it keeps that link.

A code enforcement agency can have **Default Court** set on **Agency settings → General**. New citations from that agency copy that court. Law enforcement agencies still set Default Court on the law enforcement card.

## Reports

- Juvenile OCA lines that count failure to attend school use Education Code offenses only (statute abbreviation EDC, section 25.093). An Election Code offense is not counted there.
