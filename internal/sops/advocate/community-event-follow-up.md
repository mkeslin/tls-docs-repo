## 1. Purpose

Stop event energy from dying in a notebook. Light process only — not a full community program.

## 2. Scope

**In scope:** Post-event (or during-event) capture of contacts, intros, speaking asks, and feedback.

**Out of scope:** Running a user group / newsletter calendar end-to-end (future); booth logistics.

## 3. Owner

**Advocate owner** (accountability for logging even if another founder attended).

## 4. Trigger

- Conference, association meeting, peer lunch, speaking gig, or similar  
- Customer community moment that produces names or feedback  

## 5. Outputs

- Pipedrive people/orgs with origin (e.g. Event / Conference — use existing GTM origin values when present)  
- Next activity dated ≤ 7 days for warm contacts  
- Feedback bullets for Product (work item or shared note)  
- If a customer offered intros/reference: hand to [Capture referral](capture-referral.md) / [Request customer reference](request-customer-reference.md)

## 6. Procedure

1. **Within one business day**, open notes from the event.  
2. **Triage each contact:** lead · existing customer · partner · ignore.  
3. **Log leads** in Pipedrive; set origin; schedule first touch.  
4. **Log customer touches** on their org (praise, pain, intro offers).  
5. **Capture speaking / community opportunities** (who, topic, date if any).  
6. **Send Product feedback** in one short list (no ship-date promises).  
7. **Update Hub Advocate plan** if this event was a period priority.
