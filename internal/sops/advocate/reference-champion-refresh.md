## 1. Purpose

Prevent stale or harmful reference use — champions change jobs; accounts go At-risk; willingness expires.

## 2. Scope

**In scope:** Periodic reconfirmation of active reference champions.

**Out of scope:** First-time reference ask ([Request customer reference](request-customer-reference.md)); referral capture.

## 3. Owner

**Advocate owner**

## 4. Trigger

- Refresh date due (default **quarterly** / ≤ 90 days)  
- Health band drops to Watch/At-risk  
- Champion contact left or bounced  
- After a heavy use month (optional courtesy check)

## 5. Preconditions

- Org marked as reference champion (or soft yes) in Pipedrive  
- Recent Expand health context available when possible  

## 6. Outputs

- Updated consent / allowed uses / contact  
- Status: **Active** · **Paused** · **Removed**  
- Next refresh date  

## 7. Procedure

1. **Pull due champions** from Pipedrive notes / filter (or Hub Advocate plan priorities).  
2. **Check health** — if At-risk: **Pause** immediately; do not use on deals; notify Acquire if a live ask is in flight.  
3. **Touch champion** — short call/email: still OK to be a reference? Same allowed uses? Same contact?  
4. **Update Pipedrive** same day.  
5. **Set next refresh** ≤ 90 days (sooner if Watch).
