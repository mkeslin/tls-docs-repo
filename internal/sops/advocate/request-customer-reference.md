## 1. Purpose

Build a usable roster of customers who will speak for Thin Line — with **explicit consent** and clear boundaries — so Acquire does not scramble for ad hoc references.

## 2. Scope

**In scope:** Qualifying, asking, logging, and scheduling refresh for reference champions.

**Out of scope:** Writing published case studies (content process); running the referred-lead sale ([Capture referral](capture-referral.md) / Acquire); Community events ([Community follow-up](community-event-follow-up.md)).

## 3. Owner

**Advocate owner**

## 4. Trigger

- Customer is **Healthy** after a success check-in or hypercare-exit win  
- Customer spontaneously offers to be a reference  
- Acquire needs a reference for an active deal (prefer existing roster; if none fit, Advocate may ask a Healthy match)

Do **not** ask At-risk or strained accounts.

## 5. Preconditions

- Health band is **Healthy** (or clear Watch with strong recent win — rare exception, note why)  
- Champion / decision-maker path known  
- Pipedrive org access  

## 6. Inputs

| Input | Source |
|-------|--------|
| Health band | Expand check-in / Pipedrive |
| Modules in use | Contract / Expand notes |
| Prior consent | Pipedrive reference note |

## 7. Outputs

- Pipedrive note (or dedicated field) on the org: **Reference champion = Yes** (or Declined / Soft yes)  
- Allowed uses checked: call · quote · story · demo guest · site visit  
- Topics / modules they can speak to  
- Preferred contact method + any frequency limits  
- Next refresh date (default **quarterly**)  

## 8. Tools

| Tool | Use |

## 9. Current state

Ask successful customers informally; no qualification criteria or consent inventory. Maturity 1.

## 10. Target state

Every Healthy success moment considers a reference ask. Consented champions have allowed uses, topics, and a quarterly refresh. Acquire pulls from the roster first.

## 11. Gap analysis

| Gap | Move toward target |
|-----|--------------------|
| Asking everyone / no criteria | [Qualification checklist](../../checklists/reference-agency-qualification-checklist.md) |
| Vague “sure, call me anytime” | Explicit allowed-use list |
| Stale champions | Quarterly [refresh](reference-champion-refresh.md) |

## 12. Common risks

| Risk | Mitigation |
|------|------------|
| Asking while unhealthy | Health gate |
| Over-using one champion | Rotate; respect frequency limits |
| Prospect call without briefing | Advocate/Acquire prep the champion |
| Consent assumed from a referral ask | Separate yes for **reference** uses |

## 13. Decision trees

```text
Healthy success moment?
    │
    ├─ No / At-risk ──► Do not ask; focus on success
    │
    └─ Yes ──► Qualify (checklist) ──►
            │
            ├─ Not a fit yet ──► Skip; re-check after next win
            │
            └─ Fit ──► Ask (consent + allowed uses) ──►
                    │
                    ├─ Yes ──► Log roster + refresh date
                    │
                    ├─ Soft / later ──► Schedule revisit
                    │
                    └─ No ──► Log decline; stay helpful (referral ask may still be OK)
```

| Step | Estimate |

| Log | 10 min |

## 15. Procedure

1. **Qualify** — complete [Reference agency qualification checklist](../../checklists/reference-agency-qualification-checklist.md).  
2. **Ask** — plain language: would they help peer agencies learn from their experience? List allowed uses; get yes/no per type if needed.  
3. **Capture topics** — modules / outcomes they are comfortable discussing.  
4. **Capture preferences** — who to call, channel, “no more than N times per quarter,” blackout dates.  
5. **Log in Pipedrive** on the org (same day).  
6. **Set refresh** — next [champion refresh](reference-champion-refresh.md) ≤ **90 days**.  
7. **Optional:** if they also have intros, run [Capture referral](capture-referral.md).

## 16. Verification

- [ ] Qualification notes recorded  
- [ ] Consent + allowed uses logged  
- [ ] Topics / modules listed  
- [ ] Contact preferences + frequency limits logged  
- [ ] Next refresh dated  

## 17. Failure and escalation

| Situation | Action |
|-----------|--------|
| Customer uncomfortable | Accept no; do not pressure |
| Acquire needs a reference tomorrow | Use roster; if empty, Advocate asks best Healthy fit with full consent |
| Champion left the agency | Mark inactive; find new champion or remove |
