## Deliver prepares

### Context

- [ ] Modules live listed
- [ ] Champion + backup contacts named (phone/email)
- [ ] Training status summarized (who / what / gaps)
- [ ] Open hypercare issues listed (severity + owner)
- [ ] Known Watch/At-risk signals called out honestly

### Readiness

- [ ] No blocking P1 — **or** explicit decision to delay handoff
- [ ] Support aware of impending steady-state ownership
- [ ] Engagement workspace link / location shared with Expand owner

---

## Huddle

- [ ] Deliver + Expand owner met (Support optional)
- [ ] Open risks walked
- [ ] Expand owner **accepted** — or gaps listed with owner/date

---

## Expand accepts

- [ ] Initial health band set (often Watch for brand-new; At-risk if signals)
- [ ] Day **30** success check-in scheduled (sooner if At-risk)
- [ ] Pipedrive activity: handoff accepted + first check-in date
- [ ] Account on Expand cadence (30 / 60 / 90 then quarterly if Healthy)
- [ ] Hub Expand plan updated if in current period focus

---

## Support

- [ ] Confirmed: new tickets → steady-state Support (not Deliver hypercare)
