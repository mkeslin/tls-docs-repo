# Expansion conversation checklist

**Document type:** Checklist  
**Status:** v0.1 (target-state)  
**Use during:** [Expand account](../sops/expand/expand-account.md)  
**Owner:** Expand owner

---

## Identity

| Field | Value |
|-------|--------|
| Agency / org | |
| Trigger | ★ Check-in probe · ★ Customer inquiry · ★ Other: |
| Health band | ★ Healthy · ★ Watch · ★ At-risk (inquiry exception) |
| Module / site / seats in focus | |

---

## Gate

- [ ] Health gate OK **or** customer-initiated inquiry noted
- [ ] Not pitching over an open P1 / active cancellation fight (listen only if they insist)

---

## Prepare

- [ ] Contracted modules vs available upsell list reviewed
- [ ] Rough value / packaging known (or “needs quote” flagged)
- [ ] Known objections / prior “not now” notes reviewed
- [ ] Pricing guardrails in mind (no freestyle discounts)

---

## Conversation

- [ ] Confirmed problem / job-to-be-done (not feature tourism)
- [ ] Fit explained in customer language
- [ ] Interest level clear: ★ Hot · ★ Warm · ★ Nurture · ★ No
- [ ] No invented product ship dates
- [ ] Next step agreed (demo / quote / follow-up / stop)

---

## Pipedrive (same business day if real interest)

- [ ] **Opportunity** created or updated (org linked)
- [ ] Title includes agency + module/site
- [ ] Stage set; expected close date (even rough)
- [ ] Next activity dated (≤ 7 days)
- [ ] Activity note from the conversation

---

## Follow-through

- [ ] Quote / Acquire path started if needed
- [ ] Expand two-week plan priority updated
- [ ] If “not now”: success cadence continues; no zombie opportunity without a reason
