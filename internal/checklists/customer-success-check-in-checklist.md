## Before the touch

- [ ] Confirm cadence bucket (new / healthy / watch / at-risk)
- [ ] Skim last Pipedrive notes and open Support items
- [ ] Complete or refresh [Account health / risk checklist](account-health-risk-checklist.md)
- [ ] Know modules contracted vs believed in use
- [ ] Meeting / outreach confirmed

---

## During the check-in

### Relationship

- [ ] Champion / primary contact still correct
- [ ] Decision-maker path known if champion differs
- [ ] Customer feels heard on open frustrations (park hard bugs to Support)

### Adoption

- [ ] Sold modules in daily / weekly use as expected
- [ ] Training gaps named (role + topic)
- [ ] Any “shelfware” module discussed honestly

### Outcomes

- [ ] Customer can name the operational win they are getting (or the gap)
- [ ] No surprise “we’re evaluating leaving” (if yes → At-risk path)

### Expansion probe *(Healthy, or customer inquiry only)*

- [ ] Asked lightly about additional modules / sites / seats — **or** N/A (At-risk)
- [ ] If interest: schedule follow-up via [Expand account](../sops/expand/expand-account.md)

### Close

- [ ] Agreed next step + date
- [ ] Next check-in date set per cadence

---

## After the touch

- [ ] Pipedrive **activity** logged same day (health band, summary, next step, next check-in)
- [ ] At-risk ⇒ next action ≤ 14 days on calendar / Pipedrive
- [ ] Hub Expand plan priority updated if this account is in the current two-week focus
- [ ] Expansion opportunity created if real interest ([expansion conversation checklist](expansion-conversation-checklist.md))
