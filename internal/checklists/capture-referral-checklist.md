# Capture referral checklist

**Document type:** Checklist  
**Status:** v0.1 (target-state)  
**Use during:** [Capture referral](../sops/advocate/capture-referral.md)  
**Owner:** Advocate owner (ask + log) · Acquire (first touch)

---

## Identity

| Field | Value |
|-------|--------|
| Referring agency | |
| Who asked / date | |
| Trigger | ★ Hypercare exit · ★ Healthy check-in · ★ Praise · ★ Spontaneous · ★ Other |

---

## Gate

- [ ] Relationship in good standing (not At-risk / not open P1 fight)
- [ ] Success moment is real (or customer already offered an intro)

---

## Ask

- [ ] Used [Referral ask script](../templates/referral-ask.md) or plain equivalent
- [ ] Agency name(s) captured
- [ ] Person / role if known
- [ ] Context (why they might care)
- [ ] Permission to use referrer’s name — ★ Yes · ★ No

---

## Outcome

| Result | Next |
|--------|------|
| ★ Named intro | Log + Acquire first touch |
| ★ Thinking | Follow-up ask dated in Pipedrive |
| ★ Declined | Log; no pressure |

---

## Pipedrive (same day if named intro)

- [ ] Ask outcome noted on **referring** org
- [ ] Referred org/person created or updated
- [ ] Lead origin = **Referral**
- [ ] Referring agency attribution recorded (field or note)
- [ ] Name-permission yes/no recorded
- [ ] Next activity for Acquire first touch (same day when possible)

---

## Close the loop (preferred)

- [ ] Thank referrer after a good first conversation (no confidential deal detail)
