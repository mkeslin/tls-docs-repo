## Health gate

- [ ] Current health band checked (Expand / Pipedrive / Support)
- [ ] If **At-risk** → status **Paused**; Acquire notified if a live ask exists; stop here after logging

---

## Reconfirm

- [ ] Still willing to be a reference
- [ ] Allowed uses still accurate (call / quote / story / demo / visit)
- [ ] Topics / modules still accurate
- [ ] Contact still correct (name, phone, email)
- [ ] Frequency limits updated if needed

---

## Status

| Status | When |
|--------|------|
| ★ Active | Willing + Healthy enough |
| ★ Paused | At-risk / temporary “not now” |
| ★ Removed | Permanent no / left agency / bad fit |

---

## Pipedrive

- [ ] Status + notes updated same day
- [ ] Next refresh dated ≤ **90 days** (sooner if Watch / soft)
